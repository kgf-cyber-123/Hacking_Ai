# Hacking_Ai
# 🚀 Web Workspace & Custom AI Chat Application

একটি আধুনিক, দ্রুতগতির এবং সুরক্ষিত ক্লায়েন্ট-সাইড ওয়েব অ্যাপ্লিকেশন। এতে কাস্টম REST API-এর মাধ্যমে রিয়েল-টাইম AI প্রম্পট হ্যান্ডলিং, লোকাল চ্যাট এক্সপোর্ট, সম্পূর্ণ ব্যাকআপ-রিস্টোর, সার্চিং এবং রেসপন্সিভ থিমিং সুবিধা অন্তর্ভুক্ত রয়েছে।

---

## 🛠️ প্রধান ফিচারসমূহ (Key Features)

- **Custom API Integration**: সরাসরি কাস্টম সার্ভার API (`kalyan?massage=`) এনডপয়েন্টের মাধ্যমে প্রতিক্রিয়া তৈরি।
- **Security & XSS Protection**: HTML এস্কেপিং, কাস্টম সেনিটাইজেশন এবং ফাইল সাইজ/টাইপ নিরাপত্তা ভ্যালিডেশন।
- **Local Storage Management**: চ্যাট হিস্ট্রি, ইউজারের কাস্টম থিম প্রেফারেন্স এবং অ্যানালিটিক্স ডাটা সম্পূর্ণ ব্রাউজারে সংরক্ষিত থাকে।
- **Chat Search & Highlight**: সার্চ বারের মাধ্যমে ডাইনামিকালি চ্যাট হিস্ট্রি খোঁজা এবং কাস্টম `<mark>` ট্যাগের মাধ্যমে টেক্সট হাইলাইট করা।
- **Export & Backup System**:
  - চ্যাট ফাইল `.md`, `.txt`, `.html`, এবং `.json` ফরম্যাটে এক্সপোর্ট করার সুবিধা।
  - সমস্ত অ্যাপ্লিকেশন ডাটা একসাথে JSON ব্যাকআপ নেওয়া এবং যেকোনো সময় রিস্টোর করার সুবিধা।
- **Quick Prompt Templates**: এক ক্লিকে ব্যবহারের জন্য ইন্টারেক্টিভ কাস্টম চিপস টেমপ্লেট।
- **Keyboard Shortcuts**: `Ctrl + Enter` (মেসেজ সেন্ড), `Ctrl + Shift + F` (সার্চ), `Ctrl + N` (নতুন চ্যাট) এবং `Escape` (মোডাল বন্ধ)।
- **Theme Engine**: ডার্ক থিম (GitHub Dark), লাইট থিম (GitHub Light) এবং হাই কনট্রাস্ট মোড উইথ সিস্টেম ডিটেকশন।
- **Offline & Network Monitor**: ইন্টারনেট সংযোগ বিচ্ছিন্ন বা যুক্ত হলে স্বয়ংক্রিয় নোটিফিকেশন অ্যালার্ট।
